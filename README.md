# energy-courtroom-3d
مشروع تفاعلي ثلاثي الأبعاد باللغة العربية (Three.js) يجمع بين الفيزياء والتربية المدنية تحت عنوان «محكمة الطاقة 3D: الطاقة والمواطنة»، يناقش الكفاءة وانحفاظ الطاقة عبر خمس قضايا وسرد فيديو من سبعة مقاطع وملخص للطاقات ونصائح الحفاظ عليها وشهادة مواطنة بيئية — إعداد الطالبة: مروة بكاوي | القسم: 2 رياضي.
